# Overview

## What is this repository?

This repository presents a **Foundational Quantitative Research (FQR)** framework for modelling financial markets as **multi-layer, adaptive systems**.

Rather than treating markets as isolated time series or static statistical processes, we model them as:

- **Networks of assets and markets**
- **Networks of interacting agents**
- **Rule-driven dynamical systems**
- **Layered valuation surfaces evolving through time**

This approach aims to bridge:
- Market microstructure (order flow, liquidity, execution)
- Macro dynamics (regimes, fundamentals, systemic risk)
- Agent behaviour (strategies, learning, interaction)

---

## Core Idea

Markets are not a single process.

They are a **coupled system of interacting layers**, where:

- Structure (graphs) defines relationships
- Rules define evolution
- Agents create dynamics
- Valuation emerges from interaction

This repository formalises that system.

---

## Why this matters

Traditional models often fail because they isolate components:

- Pure time-series models ignore structure
- Agent-based models ignore valuation consistency
- Fundamental models ignore microstructure
- Execution models ignore macro regimes

This framework unifies these into a **single coherent system** capable of:

- Simulating realistic market dynamics
- Supporting strategy research and backtesting
- Enabling risk-aware decision systems
- Bridging theory and implementation
